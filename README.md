# Venus radiation transfer model

Модель переноса теплового излучения в атмосфере Венеры.  
Реализован line‑by‑line расчёт коэффициентов поглощения $CO_2$ и $O_3$ с использованием HAPI (HITRAN), а также аэрозольного ослабления (4 моды $H_2SO_4$).  
Поддерживается кэширование результатов, параллельные вычисления, расчёт уходящего излучения на верхней границе атмосферы.

## Структура проекта

```bash
venus_radiative_transfer/
├── data/
│   ├── raw/                     # исходные данные параметров атмосферы и аэрозолей
│   └── processed/               # кэш HDF5 (коэффциенты поглощения по слоям) и результаты
├── src/
│   └── venus_radiative_transfer/
│       ├── config.py            # все параметры модели
│       ├── data/
│       │   ├── reader.py        # загрузка профилей
│       │   ├── profiles.py      # генерация VMR озон/аэрозоля
│       │   └── cache.py         # кэширование в HDF5
│       ├── physics/
│       │   ├── absorption.py    # расчёт k_abs через HAPI
│       │   ├── planck.py        # функция Планка
│       │   └── radiation.py     # Расчет переноса излучения
│       ├── run.py               # главный скрипт
│       └── plot.py              # построение графиков
└── README.md
```
