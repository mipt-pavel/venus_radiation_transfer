# Venus radiation transfer model

Модель переноса теплового излучения в атмосфере Венеры.  
Реализован line‑by‑line расчёт коэффициентов поглощения $CO_2$ и $O_3$ с использованием HAPI (HITRAN), а также аэрозольного ослабления (4 моды $H_2SO_4$).  
Поддерживается кэширование результатов, параллельные вычисления, расчёт уходящего излучения на верхней границе атмосферы.

## Структура проекта

venus_radiative_transfer/
├── data/
│ ├── raw/ # исходные профили параметров атмосферы, аэрозольные параметры
│ ├── processed/ # кэш HDF5 (коэффициенты поглощения по слоям) и промежуточные результаты
| └── temp/ # временные файлы в ходе выполнения программы
├── src/
│ └── venus_radiative_transfer/
│ ├── config.py # параметры модели
│ ├── data/ # загрузка профилей, кэширование
│ ├── physics/ # absorption, planck, radiation
│ ├── run.py # основной скрипт
│ └── plot.py
└── README.md
